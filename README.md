# 飞书剪存pro

将当前网页一键保存为排版后的飞书云文档，并同步建立可检索的飞书多维表格记录。

![飞书剪存pro](store-listing/assets/promo-large-1400x560.png)

> 本项目是独立开源工具，并非飞书或 Lark 官方产品。飞书和 Lark 是其各自权利人的商标。

## 产品特色

- **完整正文**：三级提取机制识别文章真实标题、正文、图片、表格、列表、引用和标题层级。
- **AI 整理**：默认调用本机 Ollama 重新组织 100–200 字内容摘要，只总结文章中的核心事实、措施、进展与影响，并确保以完整句子结束；仅根据清洗后的标题和正文提取 2–3 个重点标签，每个 2–5 个字。
- **受保护图片**：浏览器和本机服务两级获取正文图片，兼容延迟加载、访问校验和禁止外链的来源站点。
- **中文排版**：文档标题与图片居中，普通正文段落首行空两格，并保留网页原有的居中或右对齐段落。
- **格式保真**：图片题注写入飞书图片描述，保留 GIF、代码语言、LaTeX 公式和复杂表格结构。
- **通用清理**：过滤导航、页脚、分享按钮、编辑审核信息等网站要素。
- **双重归档**：同时创建云文档与多维表格记录，标题、日期、发布单位、标签和原链接保持一致。
- **后台续存**：点击后任务交由浏览器后台和本机服务持续处理，切换标签页或关闭剪存弹窗不会中断。
- **可控位置**：默认在云盘根目录创建 `飞书剪存` 文件夹；只有点击“选择保存文件夹”后才读取一级文件夹，进入文件夹后再按需读取下一层。云文档和名称可修改的多维表格始终保存在同一位置。
- **删除联动**：云文档与对应记录任意一端被明确删除后，自动删除另一端。
- **两层查重**：本地记录让扩展图标即时显示对号；点击剪存时再查询飞书多维表格，支持跨浏览器、跨设备发现重复记录。
- **分类诊断**：区分页面读取、正文识别、本机服务、飞书授权、云文档和多维表格写入错误。
- **隐私优先**：只在用户点击时读取当前网页；没有开发者中转服务器、广告或行为分析。

## 安装要求

浏览器扩展需要本机配套服务才能连接飞书。首次使用需准备：

- Chrome 或 Microsoft Edge
- Node.js 18 或更高版本
- 飞书或 Lark 账号
- 飞书官方 [`lark-cli`](https://github.com/larksuite/cli)

完整步骤见 [安装指南](INSTALL.md)。商店安装扩展后，仍需按安装指南完成一次本机服务和飞书授权配置。

- [GitHub Releases 下载](https://github.com/lproc2006/feishu-clipper-pro/releases)
- Chrome Web Store：提交审核后更新
- Microsoft Edge Add-ons：提交审核后更新

## 使用方法

1. 打开要保存的文章页面。
2. 点击浏览器工具栏中的“飞书剪存pro”。
3. 扩展立即执行剪存，无需再次点击按钮。
4. 出现“已剪存完毕”后，可打开飞书云文档或网页剪存库；该网址再次打开时，扩展图标会显示对号。

点击弹窗右上角设置图标后，只有主动点击“选择保存文件夹”，本机服务才会使用当前 `lark-cli` 用户授权读取飞书云盘的一级文件夹。可选择已有文件夹、修改多维表格名称和重复网页处理方式；未选择时自动使用 `云盘根目录 / 飞书剪存`。扩展不读取飞书桌面客户端缓存、密码或登录凭据。发现跨设备重复时，默认显示已有记录，同时保留“仍然另存一份”选项。

默认保存位置：

- `云盘根目录 / 飞书剪存 / <文章标题>`
- `云盘根目录 / 飞书剪存 / 网页剪存库`

多维表格字段依次为：标题、发布时间、发布单位、原网页链接、飞书文档链接、标签、内容摘要、正文。内容摘要独立显示，不再与正文混排。

## 隐私与安全

扩展只将用户主动选择保存的当前页面内容发送到 `127.0.0.1` 本机服务。扩展会在浏览器本地保存已剪存网页的规范化网址和时间，用于显示对号；该记录不会发送给开发者。本机服务默认使用本机 Ollama 完成 AI 整理，再通过用户本人授权的 `lark-cli` 写入用户自己的飞书空间。认证信息由 `lark-cli` 管理，扩展及本项目均不保存飞书密码、应用密钥或访问令牌。

本机服务仅接受浏览器扩展来源的写入请求。详见 [隐私政策](PRIVACY.md) 与 [安全说明](SECURITY.md)。
