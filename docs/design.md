# 飞书剪存pro设计

## 目标

只保留一个核心动作：点击浏览器扩展图标后立即剪存。

执行后同时完成：

- 当前网页保存为飞书云文档。
- 当前网页元数据写入飞书多维表格。
- 云文档和多维表格默认统一放在云盘根目录下的 `飞书剪存` 文件夹中。设置页初始不读取云盘；用户点击“选择保存文件夹”后才请求一级文件夹，进入某个文件夹后再请求其直接子级，浏览与最终选择相互独立。

## 默认资源

- 文件夹：`云盘根目录 / 飞书剪存`
- 多维表格：`云盘根目录 / 飞书剪存 / 网页剪存库`
- 初始数据表：`剪存记录`

## 多维表格字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 标题 | text | 网页标题 |
| 发布时间 | datetime | 网页原始发布日期，仅显示年月日，与云文档一致 |
| 发布单位 | text | 网页标注的发布单位、信息来源或公众号名称 |
| 原网页链接 | text url | 原始网页 URL |
| 飞书文档链接 | text url | 自动创建的飞书云文档 |
| 标签 | multi-select | 本地规则提取的标签 |
| 内容摘要 | text | 仅总结文章重点的 100–200 字完整段落 |
| 正文 | text | 截断后的网页正文，便于检索 |

## 架构

```text
浏览器扩展
  ├─ popup: 发起后台任务、查询进度并显示完成提示
  ├─ background: 固定原标签页、提交持续任务、记录网址并维护图标对号
  ├─ Readability: 提取文章主体和真实标题
  ├─ content script: 结构化正文、图片与通用网站要素清理
  └─ fetch localhost

本机服务 127.0.0.1:8787
  ├─ clipJobs: 独立执行剪存任务，弹窗或浏览器标签切换不影响任务
  ├─ ensureWorkspace()
  │   ├─ 读取用户选择的 Drive 文件夹，或找到/创建默认文件夹: 飞书剪存
  │   └─ 找到或创建 Base: 网页剪存库
  ├─ createDoc()
  │   └─ 在飞书剪存文件夹创建含排版与图片的云文档
  ├─ createRecord()
  │   └─ 写入剪存记录表
  ├─ registerPair()
  │   └─ 持久保存云文档 token 与多维表格记录 ID 的关联
  └─ syncDeletionPairs()
      ├─ 每 15 秒核对云文档和记录是否存在
      └─ 得到明确删除结果后删除对应端，并回查确认；未确认则保留关联重试
```

## 安全边界

- 浏览器扩展不保存飞书 app secret、access token 或用户令牌。
- 所有飞书写入走本机已授权 `lark-cli --as user`。
- 本机服务只监听 `127.0.0.1`。
- CORS 只面向本地插件请求开放。
- 删除同步只作用于插件登记或从 `飞书文档链接` 恢复出的配对。
- 文件移动不视为删除；网络失败、权限错误和一次性缺失不会触发级联删除。

## 当前范围

包含：

- 点击扩展图标即自动剪存，不显示二次确认按钮。
- 成功后显示“已剪存完毕”，并为当前浏览器中已剪存的网址显示图标对号。
- 真实文章标题识别，云文档与多维表格共用同一个标题值。
- 原网页链接、标签、发布时间、发布单位由同一个元数据对象写入云文档和多维表格。
- 阅读模式正文提取与通用网站要素清理。
- 段落、标题、列表、引用、代码和正文图片按顺序写入云文档。
- 网页表格保留行列、表头、合并单元格、列宽和基础单元格样式。
- 本机 AI 生成只包含文章重点、以完整句子结束的 100–200 字摘要，以及默认 2–3 个重点标签，每个不超过 5 个字；模型不可用时回退本地内容规则。
- 云文档标题、图片、题注与公式居中；普通正文段落使用两个全角空格实现中文首行缩进，并保留来源页已有的居中或右对齐。
- 浏览器取回受保护正文图片并通过飞书原生媒体接口上传。
- 自动创建文件夹、Base、云文档、记录。
- 返回保存结果。

暂不包含：

- OCR。
- 视频、音频和交互式图表归档。
- 多目标库路由。

这些可在 v1 增量加入。
