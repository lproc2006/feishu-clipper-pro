# 飞书剪存pro设计

## 目标

只保留一个核心动作：`完整剪存`。

执行后同时完成：

- 当前网页保存为飞书云文档。
- 当前网页元数据写入飞书多维表格。
- 云文档和多维表格统一放在云盘根目录下的 `飞书剪存` 文件夹中。

## 默认资源

- 文件夹：`云盘根目录 / 飞书剪存`
- 多维表格：`云盘根目录 / 飞书剪存 / 网页剪存库`
- 初始数据表：`剪存记录`

## 多维表格字段

| 字段 | 类型 | 说明 |
|---|---|---|
| 标题 | text | 网页标题 |
| 发布时间 | datetime | 网页原始发布日期，仅显示年月日，与云文档一致 |
| 发布单位 | text | 网页标注的发布单位、信息来源或公众号名称 |
| 原网页链接 | text url | 原始网页 URL |
| 飞书文档链接 | text url | 自动创建的飞书云文档 |
| 标签 | multi-select | 本地规则提取的标签 |
| 正文 | text | 截断后的网页正文，便于检索 |

## 架构

```text
浏览器扩展
  ├─ popup: 只有一个完整剪存按钮
  ├─ Readability: 提取文章主体和真实标题
  ├─ content script: 结构化正文、图片与通用网站要素清理
  └─ fetch localhost

本机服务 127.0.0.1:8787
  ├─ ensureWorkspace()
  │   ├─ 找到或创建 Drive 文件夹: 飞书剪存
  │   └─ 找到或创建 Base: 网页剪存库
  ├─ createDoc()
  │   └─ 在飞书剪存文件夹创建含排版与图片的云文档
  ├─ createRecord()
  │   └─ 写入剪存记录表
  ├─ registerPair()
  │   └─ 持久保存云文档 token 与多维表格记录 ID 的关联
  └─ syncDeletionPairs()
      ├─ 每 15 秒核对云文档和记录是否存在
      └─ 得到明确删除结果后删除对应端，并回查确认；未确认则保留关联重试
```

## 安全边界

- 浏览器扩展不保存飞书 app secret、access token 或用户令牌。
- 所有飞书写入走本机已授权 `lark-cli --as user`。
- 本机服务只监听 `127.0.0.1`。
- CORS 只面向本地插件请求开放。
- 删除同步只作用于插件登记或从 `飞书文档链接` 恢复出的配对。
- 文件移动不视为删除；网络失败、权限错误和一次性缺失不会触发级联删除。

## 当前范围

包含：

- 完整剪存按钮。
- 真实文章标题识别，云文档与多维表格共用同一个标题值。
- 原网页链接、标签、发布时间、发布单位由同一个元数据对象写入云文档和多维表格。
- 阅读模式正文提取与通用网站要素清理。
- 段落、标题、列表、引用、代码和正文图片按顺序写入云文档。
- 网页表格保留行列、表头、合并单元格、列宽和基础单元格样式。
- 本地标签规则。
- 自动创建文件夹、Base、云文档、记录。
- 返回保存结果。

暂不包含：

- OCR。
- AI 摘要。
- 视频、音频和交互式图表归档。
- 多目标库路由。

这些可在 v1 增量加入。
